# Vladimir Petrov — Portfolio

Portfolio site built with Next.js, TypeScript and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Project structure

- `src/app` - routes and app shell
- `src/components` - reusable UI blocks
- `src/data/projects.ts` - project content
- `src/types/project.ts` - shared project types
- `src/lib/cn.ts` - class name helper
